Connect your WordPress site to ClickFused AI Writer for seamless content publishing, editing, and management.

== Description ==

ClickFused Connector is a powerful WordPress plugin that seamlessly integrates your WordPress site with the ClickFused AI Writer platform. Publish, edit, and manage your AI-generated content directly from your ClickFused dashboard without leaving your workflow.

= Features =

* **One-Click Publishing**: Publish posts from ClickFused dashboard directly to WordPress
* **Secure API Authentication**: API key-based authentication for secure connections
* **Full Post Management**: Create, update, and delete posts remotely
* **SEO Metadata Support**: Automatically sync meta descriptions and SEO data
* **Draft or Publish**: Choose to publish posts as drafts or live content
* **Bi-directional Sync**: Keep your content in sync between platforms
* **Easy Setup**: Simple configuration with API key authentication
* **REST API Integration**: Modern REST API endpoints for reliable communication

= How It Works =

1. Install and activate the plugin on your WordPress site
2. Generate an API key from your ClickFused Dashboard
3. Enter the API key in the plugin settings
4. Configure your WordPress site URL in ClickFused settings
5. Start publishing content directly from ClickFused!

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel
2. Go to Plugins > Add New
3. Search for "ClickFused Connector"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the plugin ZIP file
2. Log in to your WordPress admin panel
3. Go to Plugins > Add New > Upload Plugin
4. Choose the ZIP file and click "Install Now"
5. Activate the plugin

= Configuration =

1. Go to ClickFused in your WordPress admin menu
2. Check "Enable ClickFused"
3. Enter your API key (get it from ClickFused Dashboard > Settings)
4. Click "Save Settings"
5. Click "Test Connection" to verify the setup

== Frequently Asked Questions ==

= Do I need a ClickFused account? =

Yes, you need a free ClickFused account. Sign up at clickfused.com

= Is this plugin free? =

Yes, the plugin is completely free. ClickFused offers a free tier with all core features.

= How do I get an API key? =

Log in to your ClickFused dashboard, go to Settings, and generate a new API key.

= Can I publish to multiple WordPress sites? =

Yes, you can connect multiple WordPress sites by installing this plugin on each site and configuring them in your ClickFused dashboard.

= Is my content secure? =

Yes, all communication uses secure API keys and HTTPS connections. Your API key is stored securely in your WordPress database.

= What happens if I deactivate the plugin? =

Your published posts remain on WordPress. You just won't be able to publish new content from ClickFused until you reactivate the plugin.

= Does this work with custom post types? =

Currently, the plugin supports standard WordPress posts. Custom post type support is coming in a future update.

= Can I unpublish posts from ClickFused? =

Yes, you can delete posts remotely from your ClickFused dashboard.
